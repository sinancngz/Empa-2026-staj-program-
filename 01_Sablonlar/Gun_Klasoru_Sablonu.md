# Gün Klasörü Şablonu

Her gün klasörü şu yapıda olmalı:

```
XX_YYYY-MM-DD_GunAdi/
├── 00_GUN_PLANI.md          ← bugün ne yapılacak
├── 01_Anlatim_Notlari.md    ← o gün anlatılacak konu (kısa iskelet)
├── 02_Gorevler.md           ← kolay / orta / zor (herkes aynı)
├── mentor_notlari.md        ← sade tik listesi
├── kaynaklar/               ← o güne ait dökümanlar (mentör ekler)
│   └── README.md
└── teslimler/
    ├── README.md
    └── Stajyer_A..E/
        ├── rapor/gunluk_rapor.md
        └── proje/           ← proje dosyaları
```

## Kurallar

| Olacak | Olmayacak |
|--------|-----------|
| Kaynaklar klasörü | Lab notu klasörü |
| Günlük rapor | Kanıt / screenshot zorunluluğu |
| Proje klasörü (`proje/`) | Ayrı A–E görev paketleri |
| Kolay / orta / zor (ortak) | Puanlama / rubrik |
| Anlatım dökümanı (konu) | Şişirilmiş mentor formu |

## Görev biçimi

Herkes aynı üç seviyeyi yapar:

1. **Kolay** — temel
2. **Orta** — birleştirme
3. **Zor** — biraz daha ürün gibi

Mentör sadece tik atar.
